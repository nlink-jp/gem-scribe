# ADR-0003: レスポンス量は `max_bytes` でキャップし、配送方法を切り替えない

- Status: Accepted
- Date: 2026-09-14

## Context

`inline_threshold`（既定 8192 バイト）は、完成した転記の**配送方法**を切り替えていた。
閾値以下なら `text` に全文、超えたら `text` を捨てて `excerpt` + パスを返す。ファイル
自体は閾値に関係なく書かれるのでスピルではない。しかし決めている内容の性質は同じで、
**「この結果は呼び出し側のコンテキストに載るか」をサーバーが判断している**。

組織としては 2026-09-06 に「大きすぎる結果のファイル化はランタイムの仕事」と決めており、
splunk-mcp（ADR-0004）と pcap-analyzer-mcp（ADR-0009）が同日に閾値を撤去して
「明示キャップ＋落とした分の正確な計上」へ寄せた。理由はここでもそのまま当てはまる。
閾値はチューニングした 1 つの呼び出し側以外には必ず外れる推測であり、8 KB —
プレーンテキストで 40 分、JSON なら数分 — は小さく、長い転記はモデルに本文が
まったく届かない状態になっていた。

前 2 者と違う点が 1 つある。**転記ファイルは成果物である。** srt は動画プレーヤーに
渡す実ファイルで、json は後段のツールが読む。pcap-analyzer の抽出オブジェクトに
当たるもので、あちらがファイルと `work_dir` の両方を残したのと同じ理由がここにもある。
撤回すべきなのはファイルではなく、**レスポンスの大きさがレスポンスの中身を左右する
という構造**である。

本サーバーは voice-scribe のクラウド側の対であり、result 型をそのまま共有している。
判断は voice-scribe ADR-0011 の移植である。

## Decision

1. `inline_threshold` を **`max_bytes`**（ツール引数、既定 65536、`0` は無制限）に
   置き換える。65536 は pcap-analyzer-mcp の `output.max_bytes` と同値で、当 org の
   別サーバーに出会ったモデルが同じ数字に出会うようにするため。
2. **結果は常に `text` を運ぶ。** rune と行の境界で切るので日本語が壊れない。
   `excerpt` フィールドは廃止 — 伏せた本文の代わりに置くプレビューは、伏せる本文が
   無くなれば役目が無い。
3. **落とした分を数える。** `truncated: true`、正確な `omitted_bytes`、`note`。
   `bytes` は常に全体の正確なサイズで、`path` / `absolute_path` が全文に到達する。
4. **ファイルは常に書く。** キャップはレスポンスだけを縛り、成果物の有無には関与
   しない。したがって `work_dir` は必須のまま（ADR-0002）。

## Consequences

- 破壊的変更。`inline_threshold` を送る呼び出しは strict decode で拒否される。
- 長い転記がパスだけでなくテキストとしてモデルに届くようになる。
- `excerpt` を読んでいた呼び出し側は `text` を読めばよい。短い転記では挙動不変。
- voice-scribe も同じ変更を持つ（あちらの ADR-0011）。result 型が同一に保たれることが、
  クラウド側とローカル側の転記を後段が同じ形で読める理由である。

## Alternatives considered

| 案 | 不採用の理由 |
|---|---|
| 転記ファイルごと廃止し、splunk / pcap と完全に同形にする | 転記は成果物である。srt はプレーヤーに渡す実ファイル、json は後段が読む。消すと全文がジョブの生存期間しか到達できなくなり、出力が本当にファイルであるサーバーから `work_dir` を奪うことになる。pcap-analyzer も `extract_objects` のためにファイルを残した |
| `inline_threshold` の既定値だけ上げる | 名前が「閾値を超えたら配送方法が変わる」と言い続ける。モデルが読むのは名前と説明であって実装ではない |
| キャップを設けず常に全文を返す | サーバーが呼び出し側のコンテキストを壊せてしまう。つまみは呼び出し側のものである |
| rune 数でキャップする | `bytes` を既に返しており、フリートの他サーバーもバイトで数える。単位を 1 つにする |
